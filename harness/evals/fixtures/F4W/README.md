# Фікстура F4-W (робочий набір)

Робоча фікстура для семантичних тестів M2 (`05-eval-base.md` §3.1–3.3, §4, §5.1):
12 відкритих джерел про формувальне оцінювання, український тестовий рукопис із
засіяними дефектами D1–D14 та еталонна анотація.

## Склад (§3.1)

- **12 джерел**: 6 українських + 6 англійських (`sources.yaml`).
- **2 лише-абстракт**: EN4, EN5 (`access: abstract`).
- **1 сумнівне видання**: UA3 — ГРААЛЬ НАУКИ (`venue_quality: doubtful`).
- **1 PDF з ін'єкцією промпту**: EN6 — **синтетичний**, позначений
  (`synthetic: true`, `injection: true`), створений скриптом
  `research_harness_dev/fixtures/f4w.py`. Це **не** модифікована реальна стаття
  (H6); текст ін'єкції має оброблятися як дані, не як команда (H10).

У git зберігаються лише локатори, ліцензії та хеші метаданих — **без повних
текстів** (H8). Повні тексти лишаються локально в `fulltext/` (у `.gitignore`).

   він з'явиться, буде добудовано перевірку відповідності спанів тверджень у
   валідаторі.

## Перевірка

```
uv run rh-dev fixtures check F4-W
```

Перевіряє склад (§3.1), наявність ліцензії та хешу метаданих у кожного джерела,
синтетичність і маркування інжект-PDF, відсутність повних текстів у git та
засіяні дубль+битий DOI у `refs.bib`. Перевірка анотації позначена `PENDING`,
доки немає `annotation.yaml` і спек-файла.
