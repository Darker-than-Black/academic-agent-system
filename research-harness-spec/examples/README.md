# Приклад контракту

`claim.example.json` — структурний placeholder, не реальний результат. Нульовий hash і неіснуючий result_ref мають пройти лише schema validation та провалити cross-reference validation для експорту. Значення не повинні потрапляти у статтю.

Приклад містить базові envelope-поля; schemas інших сутностей implementer має додати відповідно до 06-contracts. JSON Schema перевіряє форму, не істинність або існування evidence.
