# Крок 3 — Вимоги v0.2.1: FR, NFR, ASR і трасування

Дата: 2026-10-27; редакція v0.2.1 від 2026-10-28. Статус: **погоджено автором** (v0.2 — 2026-10-27, v0.2.1 — 2026-10-28; рішення — §9). Крок Е0 (етап 0) за `stage-0/00-stage0-plan.md`.
Вхід: `04-requirements.md` (v0.1), `05-architecture.md`, `11-vision-addendum-2026-10-20.md` §11, `stage-0/01-materials-review.md` (§5, §7), `stage-0/02-lifecycle.md` (§12, §14), `12-reuse-registry-verified-2026-10-27.md` §7; для v0.2.1 — бачення автора щодо роботи з кінцевим користувачем і структури дисертації (2026-10-27/28), `stage-0/05-eval-base.md` §11–12.
ADR — окремі файли в `stage-0/adr/` (індекс у §6).

Правила документа:
- **MUST** — умова приймання того milestone, до якого вимогу віднесено (§7); **SHOULD** — бажано, відхилення записується; **LATER** — поза M1–M6.
- **MVP** = M1–M5. ML-гілка (M6) — одразу після MVP; її FR зберігають пріоритет MUST для M6.
- ID з v0.1 збережено; змінений зміст позначено «змін.». Нові ID продовжують нумерацію.
- Кожна FR має хоча б один acceptance test (§5). Детальна розмітка, fixtures, метрики — `stage-0/05-eval-base.md`.
- Етапи: A0–A16 (стаття), T0–T10 (дисертація) — `02-lifecycle.md`. Milestones реалізації M1–M6 — ADR-007 rev.2.
