# ADR-026 — Антиплагіат під час написання + копірайтер як refine-прохід writer'а

Статус: прийнято 2026-11-11 (рішення автора).

## Контекст
Антиплагіат — базова перевірка для статті/дисертації, і її результат сильно
впливає на роботу. Наявний `rh overlap` (M3-10, FR-30) ловить лише **самоплагіат**
проти власного корпусу автора (`_author/corpus/`) і запускається пізно. Автор
хоче **ранню, inline-перевірку під час написання** і щоб агент активно писав /
переказував у **власну оригінальну прозу з висновками**.

Позиція автора (прийнята): будь-який текст — синтез раніше прочитаного; йдеться
**не** про «взяти 1-в-1 і покрутити слова», а про переказ наявних текстів власними
думками й висновками. Це легітимна наукова робота.

Межа, яку харнес уже кодує і яку ми тримаємо:
- `integrity/ai_use.py → _CONCEAL_PATTERNS` (**N4**) детектує й **флагає**, ніколи
  не виконує, запити «обійти детектор / evade detection / content detector».
  Копірайтер-прохід працює **по правильний бік** N4: він пише оригінально, а не
  оптимізує під обман детектора.
- **H6 / cite-binding (M4-16):** переказ вільний, але якщо конкретний
  факт/цифра/знахідка взяті з джерела X — речення зберігає `[cite:X]`. Власний
  аналіз і висновки автора — без посилання. Переказ, що зриває атрибуцію
  конкретного запозиченого факту, — не дозволяється.

## Рішення
1. **Inline similarity-гейт під час написання.** Розширити `rh overlap` так, щоб
   на drafted-юніт рахувати збіг шинглами проти **двох** корпусів:
   - власний корпус автора (`_author/corpus/`) — самоплагіат (як є);
   - **текст цитованих джерел** (excerpts + `library.sqlite` fulltext, runtime-
     only — чужий fulltext у git не входить, H8) — копіювання з джерела.
   Високий збіг → **помічник-флаг** (не твердий блок): підсвічує фрагмент і
   джерело; автор/writer або оформлює як пряму цитату (лапки + `[N, с.X]`), або
   переписує сильніше **зі збереженням** `[cite:X]`.
2. **Копірайтер — refine-прохід того самого writer-слота (ADR-002: один writer на
   об'єкт).** Не нова паралельна роль. Окремий промпт-режим «copyedit/rewrite»:
   writer драфтить із доказів → copyedit-прохід переписує в оригінальну наукову
   прозу (наративна глибина ADR-024 `writing.narrative_depth`), прибирає близькі
   до джерела формулювання, **зберігаючи** cite-binding і зв'язок твердження↔доказ.
   Той самий лок, той самий handoff; жодних змін «один writer на об'єкт».
3. **Мета — не «пройти детектор», а реально не плагіатити.** Антиплагіат
   проходиться як наслідок оригінального переказу. Similarity-гейт — помічник, не
   бар'єр; severity ≤ major, overridable.
4. **Зовнішній антиплагіат — за автором (H9/H11).** Система не інтегрує платний
   веб-сервіс і не будує свій. Вона дає чистий матеріал + внутрішній pre-check;
   фінальний прогін через сервіс ЗВО (Unicheck / StrikePlagiarism) робить автор.
   Опційно — експорт у формат для завантаження.
5. **Нічого не вигадувати (H6/H7/H10).** Показники схожості — з наявного тексту
   як дані; відсутній доступ до fulltext джерела → `unknown`, не вгадуємо.

## Альтернативи
- **Копірайтер як нова паралельна роль** — відхилено: конфліктує з «один writer
  на об'єкт» (ADR-002), тягне зміни enum context-pack/handoff та серіалізацію
  локом без потреби. Refine-прохід дає те саме дешевше.
- **Звіряти лише проти власного корпусу** — відхилено: не ловить копіювання з
  джерела під час написання (головний ризик).
- **Інтеграція платного детектора в харнес** — відхилено: H9/H11; зовнішній
  прогін лишається за автором.
- **«Переписати, щоб пройти детектор» як ціль агента** — відхилено: це N4
  (обман детектора); агент пише оригінально з атрибуцією, а не ховає запозичення.

## Наслідки
- `integrity/overlap.py` — другий корпус порівняння (цитовані джерела: excerpts +
  runtime fulltext); звіт позначає джерело збігу; пороги — дані рулпаку
  (`ua-mon-phd`/`ua-fahove-b`), draft.
- `writing` пак — правило `writing.source_paraphrase` (major, overridable):
  текст, надто близький до цитованого джерела, оформлюється цитатою або
  переписується своїми словами зі збереженням `[cite:X]`; запозичене
  формулювання не подається як оригінальне.
- `prompts/writer.md` — додати copyedit/refine-режим (оригінальний переказ,
  збереження cite-binding, обізнаність про similarity-гейт, явно НЕ обхід
  детектора — N4). Регенерувати субагентів.
- **Наступний зріз (executable):** `rh overlap` проти цитованих джерел + inline
  виклик у флоу написання + опційний експорт для зовнішнього сервісу.
- Картка M4-20 реалізує перший зріз (ADR + правило-дані + промпт).
