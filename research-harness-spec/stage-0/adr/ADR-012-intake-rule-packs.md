# ADR-012 — Обов'язковий intake і rule packs як дані

Статус: прийнято 2026-10-27 (рішення автора, 2.5 §14, 2026-10-27).

## Контекст
Вимоги до статті залежать від країни, регулятора, класу видання, конкретного журналу, установи. Вони змінюються: Перелік кат. «Б» оновлено з 1.06.2026, постанова КМУ № 1240 — 7.10.2026. Автор вимагає: harness — універсальний каркас, не заточений під одну країну чи галузь; перед кожною статтею і дисертацією — короткий опитувальник.

## Рішення
1. Intake-опитувальник обов'язковий (Q1–Q10, `02-lifecycle.md` §3А.2), з підстановкою відомих відповідей і `unknown` з наслідками; завершується G0.
2. Специфічні вимоги — лише в rule packs (versioned дані), шари: core → document_kind → study_kind → регулятор → клас видання → журнал → установа → автор.
3. Правило: id, pack, version, kind (integrity / counting / structure / format / process), applies_to, check (Д / С / Л), severity, statement, source (url, рівень достовірності), checked_at, valid_from / valid_to, review_after.
4. Композиція: форма — конкретніший шар; доброчесність і зарахування — найсуворіше; core не перевизначається; нерозв'язний конфлікт — finding.
5. Правило з рівнем [Н?] (первинне джерело не прочитано) може бути лише warning, не blocker.
6. Перед G3 і T7 — обов'язкова перевірка актуальності шарів 3–6. Розв'язаний стек фіксується з версіями в `profiles/resolved-stack.json`.
7. Перші packs: `core`, `article`, `literature-narrative`, `ml-empirical`, `ua-mon-phd`, `ua-fahove-b`, `scopus-indexed`.

## Альтернативи
- **Правила в промптах / коді** — відхилено: не версіонуються, не мають джерела, застарівають непомітно.
- **Окремі шаблони «стаття для України» і «стаття для Scopus»** — відхилено: комбінаторний вибух і дублювання.
- **Без опитувальника, лише з контексту** — відхилено автором: контекст статті неповний без явних відповідей.

## Наслідки
- Ядро CLI не містить національних правил (ASR-06).
- Нові packs (ЄС, WoS, конкретні журнали) додаються як дані без зміни коду.
- Агент може досліджувати й пропонувати packs зі статусом `draft`; `verified` — після звірки з першоджерелом.
