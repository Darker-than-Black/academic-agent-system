# ADR-020 — Дослідницька лабораторія і рівні моделей

Статус: прийнято 2026-10-28 (рішення автора, 2026-10-28). Деталі — `stage-0/06-research-agent.md`.

## Контекст
Агент-дослідник — найважливіший компонент: від нього залежить власний внесок статті. Автор вимагає флагманської моделі для дослідника і повноцінного середовища для реальних досліджень у MVP з перевіркою на тестовій статті. Дослідження з учасниками зараз неможливі через брак часу. FR-39 (runner) був LATER, tuple-валідатори — лише в ML-гілці.

## Рішення
1. **Рівні моделей.** Ролі оголошують `model_tier` (`flagship` / `strong` / `fast` / `none`); відповідність моделям — у конфігу для кожного хоста. Зараз для Claude Code: flagship = Claude Fable 5.1. Мовчазне пониження заборонене; model ID записується в кожен виклик.
2. **Лабораторія з п'яти частин:** доступ до літератури (адаптери, зокрема ERIC і українські ресурси), локальна бібліотека з текстом за сторінками, повнотекстовим індексом і детермінованою звіркою цитат, робочий стіл синтезу (матриця, позиції, прогалини, контрдокази, насичення, бібліометрія), аналітична пісочниця (ізольоване Python-середовище з lockfile, реєстр датасетів з умовами використання, скрипти + hash, result rows), лабораторний журнал.
3. **Пісочниця — у MVP (M3).** FR-39 звужено: локальний аналітичний runner — MUST; важкі й платні обчислення, тренування моделей — M6 / LATER. Tuple-валідатори, типи run і графіки з даних (FR-05, 06, 18) — M3.
4. **Без симуляції учасників:** синтетичні респонденти не є даними; `simulated` лише для пілотування інструментів.
5. **Критик з іншої родини моделей — опційний:** `rh review --engine codex` через неінтерактивний запуск Codex CLI; потребує окремих облікових даних і дозволу на зовнішні API; за замовчуванням вимкнений; fallback — Claude-критик.

## Альтернативи
- **ID моделі в описі кожного агента** — відхилено: при зміні моделі треба правити всі описи.
- **Одна модель для всіх ролей** — відхилено: дорого для масових операцій і без переваги для найважчих.
- **Лабораторія після MVP** — відхилено автором: результати лабораторії впливають на всі наступні ітерації.
- **Аналіз у довільному середовищі агента без lockfile** — відхилено: не відтворюється.

## Наслідки
- Найбільші витрати — на flagship-ролі; бюджет на кожну дослідницьку задачу і критерій зупинки обов'язкові (ADR-017).
- M2 і M3 стають важчими; ML-гілка M6 — лише ML-специфічне.
- Доступ до кожного API і умови кожного датасету перевіряються в Е1.
