# ADR-016 — Пошук: CLI-адаптери первинні, MCP опційний

Статус: прийнято 2026-10-27 (рішення автора, крок 1 Р4, 2026-10-27).

## Контекст
Адаптований literature-engine open-paper-machine покладається на MCP-пакет `academic-search-mcp` (не перевірено). v0.1: MCP — лише спосіб виклику, не архітектура. Addendum §4: каталог ресурсів; без обходу CAPTCHA і закритого доступу.

## Рішення
1. Основні адаптери пошуку і метаданих — частина CLI: Crossref, OpenAlex, Semantic Scholar, arXiv (офіційні API).
2. Ручний режим із записом у search log: Google Scholar, ResearchGate, Clarivate MJL, Scopus Sources; імпорт експортів, які дозволяє ресурс.
3. MCP-пакети — лише після аудиту коду, ліцензії і залежностей, як опційний спосіб виклику тих самих операцій.
4. Український сегмент (фахові журнали, репозитарії) — додається в source policy після перевірки доступу в M2.
5. Таймаут → `lookup_failed`, не `not_found`; недоступний ресурс → coverage gap у звіті.

## Альтернативи
- **MCP як основний шлях** — відхилено: неперевірений пакет, залежність від хоста.
- **Скрейпінг Scholar** — відхилено: CAPTCHA і умови використання.

## Наслідки
- Literature-engine адаптується під CLI-команди; посилання на неіснуючий `scripts/academic_search.py` виправляються.
- Умови використання даних про відкликання (Crossref Labs / Retraction Watch) перевіряються до adoption `retractions.py`.
